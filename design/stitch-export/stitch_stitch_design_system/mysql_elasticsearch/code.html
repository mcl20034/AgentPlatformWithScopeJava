平台所有接入的数据源仅通过安全只读隔离网关运行探活探测与受限元数据拉取；在自然语言转 SQL/DSL 查询执行阶段，内核采用严格 AST 语法树遍历校验，物理拦截任何写入、更新及 DDL 变更语句，并实施单次查询最大 15 秒超时熔断保护。数据库密码与 Token 均经由企业内部 KMS (Key Management Service) 硬件加密托管，前端界面与客户端浏览器不留存任何明文凭证。
