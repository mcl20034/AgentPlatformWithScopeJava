## Brand & Style

The design system embodies an enterprise-grade, highly disciplined, and audit-ready technological personality. It is built for data engineers, business intelligence analysts, and domain operators who need mission-critical trust, rapid scanability, and transparent model governance. The core aesthetic rejects consumer AI gimmickry—eliminating neon gradients, exaggerated floating glass effects, and playful mascots—in favor of a robust **Corporate / Modern** engineering console paradigm.

Visual language highlights:
- **Calm, High-Information Architecture**: Clear modular hierarchy organized through bounded white surfaces on soft-neutral backdrops, reminiscent of high-end developer platforms and clinical observability dashboards.
- **Explainability & Auditability**: Visual priorities are centered on structured tables, step-by-step reasoning timelines, verifiable reference tags, and readable code blocks (SQL/Elasticsearch DSL).
- **Subtle Modern Polish**: Structured 1px hairline boundaries, controlled micro-radii, restrained functional shadows, and clear status badges.

## Colors

The color palette is calibrated for high information density, long reading sessions, and functional status recognition without visual fatigue.

- **Primary & Interactive**: `#2563EB` acts as the single primary call-to-action anchor, active indicator, and interactive focus color. Its secondary shade `#1D4ED8` handles active/pressed states, while `#EFF6FF` provides subtle hover backgrounds and active navigation menu highlights.
- **Canvas & Neutral Surfaces**: `#F7F8FA` creates a crisp, light-neutral backdrop against which white cards (`#FFFFFF`) stand out cleanly. Component borders and panel dividers use hairline `#E5E7EB`.
- **Typographic Neutral Stack**: High-contrast `#1F2937` for critical metrics and primary headings, `#6B7280` for secondary explanations and table metadata, and `#9CA3AF` for placeholder hints and disabled states.
- **Status & Auditing Semantics**: Standardized pairs of text/border colors and muted 50-tint backgrounds ensure contrast-safe tags across all lifecycle states: Success (`#10B981`), Warning / Clarification (`#F59E0B`), Critical / Destructive (`#EF4444`), Processing (`#3B82F6`), and Neutral / Stopped (`#6B7280`).

## Typography

The type system prioritizes neutral legibility, numerical precision, and multilingual balance across Latin glyphs and Chinese character sets.

- **Typeface Selection**: `Inter` is paired seamlessly with modern system sans-serifs (`PingFang SC`, `Microsoft YaHei`) to render tabular data, system metrics, and analytical text cleanly. `JetBrains Mono` handles all SQL queries, DSL payloads, execution runtimes, and parameter tokens.
- **Hierarchical Balance**:
  - Page titles stay compact at `24px` / `20px` to conserve vertical space.
  - Section headers sit at `16px` with medium/semi-bold weights for rapid segment scanning.
  - Core data cells, form controls, and body text standardize at `14px` (`body-md` / `label-md`).
  - Citations, timestamps, execution elapsed time, and inline badges utilize `12px` (`caption` / `label-sm`).
- **Data & Numbers**: Tabular numerals are enforced across all metric cards and data tables to maintain stable columnar alignment during dynamic updates.

## Layout & Spacing

The layout is optimized for high-density enterprise desktop usage, with primary framing configured for `1440px` viewports (gracefully scaling down to `1280px`).

### Spatial Grid & Structure
- **Base Grid**: A disciplined 8px baseline rhythm controls all structural dimensions. 
- **Application Shell**:
  - **Left Primary Navigation**: Fixed `224px` width in standard desktop view, collapsing to an icon-rail mode of `64px` for compact screens.
  - **Header Bar**: Fixed height of `56px` to `64px` holding breadcrumbs, system status badges, and user profile management.
  - **Multi-Column Workspace (Q&A / Workspace)**:
    - *Session Panel*: `260px` left column for chat and query histories.
    - *Main Canvas*: Fluid center column (`min-width: 620px`).
    - *Execution & Trace Panel*: `360px` right dock for real-time audit steps.
  - **Slide-out Evidence Drawer**: Contextual flyout panel ranging between `520px` and `720px` for detailed SQL syntax previews, DSL traces, and document source validation.
- **Internal Card Density**: Standard card internal padding is locked between `20px` (`1.25rem`) and `24px` (`1.5rem`), while compact list items and filters rely on `8px` (`0.5rem`) and `16px` (`1rem`).

## Elevation & Depth

Visual hierarchy is built through **tonal surface stacking** and **crisp 1px boundary lines**, avoiding heavy drop shadows or intrusive lighting effects.

- **Tonal Tiers**:
  1. *Level 0 (Canvas)*: `#F7F8FA` page backdrop.
  2. *Level 1 (Default Containers & Panels)*: `#FFFFFF` cards, persistent sidebars, and data tables with an explicit `1px solid #E5E7EB` border.
  3. *Level 2 (Dropdowns & Popovers)*: `#FFFFFF` surface with an ultra-subtle ambient lift: `box-shadow: 0 4px 12px rgba(15, 23, 42, 0.06)`, bounded by a `1px solid #E5E7EB` stroke.
  4. *Level 3 (Inspection Drawers & Modals)*: Floating right drawers and centered modal dialogs with a balanced focus shadow: `box-shadow: 0 12px 32px rgba(15, 23, 42, 0.12)`, backed by a `rgba(15, 23, 42, 0.4)` scrim overlay.
- **Interactive State Elevation**: Hovering over interactive card modules or table rows does not exaggerate shadow elevation; instead, it relies on a soft background shift to `#F9FAFB` or border activation to `#2563EB`.

## Shapes

The geometric framework uses restrained, professional corner rounding that preserves high-density alignment without harsh corners.

- **Default Border Radius**:
  - Small elements (Tags, badges, status pills, inline code tags): `4px` to `6px`.
  - Core components (Buttons, input fields, select menus, tab bars): `6px` to `8px`.
  - Major containers (White cards, inspection drawers, dialog modals): `8px` to `12px`.
- **Prohibited Shapes**: Full-pill stadium buttons (`rounded-full`) and circular floating buttons are avoided across operational UI controls, reserving rounded shapes strictly for micro-badges and status presence indicators.

## Components

### Buttons
- **Primary**: Solid `#2563EB` background with white text, `8px` radius, `36px` height (40px for prominent forms). Hover triggers `#1D4ED8`. Focus displays a `2px` ring in `#EFF6FF` with `#2563EB` contour.
- **Secondary / Outline**: `#FFFFFF` background with `1px solid #E5E7EB`, text in `#1F2937`. Hover applies `#F9FAFB` and text `#111827`.
- **Subtle / Ghost**: Transparent background with `#6B7280` text, turning to `#F3F4F6` fill on hover.
- **Destructive**: Reserved strictly for irreversible operations (e.g., dropping data connections or purging sessions). Styled with red text or solid red fill, always requiring a secondary confirmation modal.

### Status Badges & Chips
- Compact `22px` height with `4px` radius, containing an inline SVG icon or animated status dot paired with explicit text.
- **Running / In-Progress**: `#EFF6FF` background, `#2563EB` text, paired with a pulsing `6px` blue dot.
- **Success / Completed**: `#ECFDF5` background, `#10B981` text, checkmark icon.
- **Warning / Clarification Required**: `#FFFBEB` background, `#F59E0B` text, alert icon.
- **Failed / Error**: `#FEF2F2` background, `#EF4444` text, cross circle icon.
- **Muted / Neutral**: `#F3F4F6` background, `#6B7280` text, clock or neutral circle icon.

### Form Inputs & Query Boxes
- **Standard Input**: Height `36px` to `40px`, `#FFFFFF` fill, `1px solid #E5E7EB` border, placeholder text in `#9CA3AF`. Labels are positioned consistently above the input at `14px` Medium (`#1F2937`).
- **Interactive Multi-line Q&A Box**: Expanding query composer, max-height `160px`, equipped with trailing action triggers (clear, upload document, submit arrow) within a consolidated container.

### Data Tables
- Fixed header pinned to the top with a `#F9FAFB` fill, `12px` uppercase bold labels (`#6B7280`), and hairline lower border.
- Row items fixed at `44px` height with subtle `#F9FAFB` hover states.
- Explicit column metadata badges (e.g., `VARCHAR`, `INT`, `DATETIME`).
- Null states rendered via distinct `#F3F4F6` badges printing `NULL` in monospace text, preventing empty cell confusion.

### Evidence & Trace Drawer
- Slide-over panel docked to the right edge (`520px`–`720px`).
- Segmented header separating generated SQL query, Elasticsearch DSL query payload, and raw retrieved chunks.
- Includes quick-copy action buttons, syntax-highlighted code canvas, and source chunk metadata tags.

### Step Execution Timeline & Chat Cards
- **Timeline**: Vertical dashed connecting line (`#E5E7EB`) linking execution milestones. Completed steps show green checkmarks; running steps display active blue spinning indicators; pending steps remain neutral grey.
- **Citation Indicators**: Inline superscripts/brackets (e.g., `[1]`, `[2]`) in `#2563EB` on light `#EFF6FF` badges that trigger the corresponding evidence drawer segment upon click.
