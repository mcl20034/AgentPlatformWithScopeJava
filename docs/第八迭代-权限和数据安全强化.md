# 第八迭代：权限和数据安全强化

## 已实现范围

### 资源访问控制

- 管理员隐式拥有全部模型、数据源和知识库权限。
- 普通用户采用默认拒绝策略，新建或已有普通用户必须由管理员明确授权。
- 账号管理页面可分别授予对话模型、数据源和知识库权限。
- 服务端在资源选项、会话列表、创建会话、历史消息、任务状态、SSE、任务取消和结果导出入口重复校验权限。
- 权限撤销后，相关会话不再出现在列表中；直接请求会返回 `CONVERSATION_RESOURCE_REVOKED`，不能继续读取历史结果或导出。
- 数据源原有表、索引和字段授权继续生效，资源授权不能绕过 SQL/DSL 安全网关。

### 账号安全

- 登录连续失败默认达到 5 次后锁定账号 15 分钟。
- 锁定参数可以通过环境变量调整。
- 管理员可在账号页面查看锁定状态并立即解锁。
- 管理员可强制注销指定用户的全部会话。
- 停用账号、重置密码仍会立即使原有会话失效。
- 登录成功会清零失败次数和锁定状态。

### 数据外泄控制

- CSV、Markdown 导出前重新检查当前资源权限，并写入独立审计动作。
- 模型返回正文默认不写入应用日志，只记录提供商、模型和字符数。
- 临时排障可设置 `PLATFORM_LOG_MODEL_CONTENT=true`，排障结束后必须恢复为 `false`。
- 数据库、模型和数据源密钥仍通过加密存储，资源授权接口不返回任何凭证。

## 配置项

```text
PLATFORM_MAX_FAILED_LOGINS=5
PLATFORM_LOGIN_LOCK_MINUTES=15
PLATFORM_LOG_MODEL_CONTENT=false
```

## 手动验收

1. 重启后端并确认 Flyway 升级到 V8。
2. 新建普通用户并完成首次改密；确认问答页没有可选模型、数据源和知识库。
3. 在账号管理中授权一个模型和一个数据源；重新打开问答页，确认只能看到被授权资源。
4. 创建会话并完成问答，然后撤销数据源权限；确认会话从列表消失，直接打开历史、任务或导出接口返回 403。
5. 重新授权后确认原会话恢复可见。
6. 连续输入 5 次错误密码，确认账号锁定；使用正确密码仍提示锁定。
7. 管理员点击“解锁”，确认用户可以再次登录。
8. 管理员点击“下线”，确认用户下一次请求返回 401。
9. 导出 CSV 和 Markdown，在运行与审计页面确认出现 `EXPORT_CSV`、`EXPORT_MARKDOWN`。
10. 检查应用日志：默认只能看到模型调用字符数，不应出现模型完整回答、密码或密钥。

## 权限边界

本迭代实现用户到资源的直接授权。复杂组织架构需要的用户组、部门继承、同一数据源针对不同用户设置不同的行过滤条件，可在后续迭代建立策略模型；当前数据源字段范围由管理员统一发布，所有获授权用户共享该数据源版本的受控范围。
